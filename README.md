# FamTree 🌳

A modern, interactive family tree visualization application built with React, Vite, and React Flow.

## Features ✨

- **Interactive Visualization:** Explore family trees with a smooth, interactive graphing interface powered by `@xyflow/react`.
- **Auto Layout:** Automatic node positioning for optimal readability using `dagre`.
- **Data Import:** Read and parse family data from Excel files using `xlsx`.
- **State Management:** Efficient and predictable application state managed with `zustand`.
- **Fast & Modern:** Built on top of Vite for lightning-fast HMR and modern frontend tooling.

## Tech Stack 🛠️

- **Framework:** React 19
- **Build Tool:** Vite
- **Routing:** React Router
- **Graphing:** React Flow (`@xyflow/react`)
- **Layout:** Dagre
- **State:** Zustand
- **Data Parsing:** SheetJS (`xlsx`)

## Getting Started 🚀

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/OhmCodes2002/FamTree.git
   cd FamTree/famtree-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173/` (or the network URL provided in your terminal).

## Scripts 📝
- `npm run dev` - Start the Vite development server.
- `npm run build` - Build the app for production.
- `npm run preview` - Locally preview the production build.
